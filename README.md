# Тест: test_set_book_genre. Проверил, что книгу можно добавить, что изначально у неё нет жанра, что метод set_book_genre успешно ставит жанр, что после установки жанр действительно сохранился.
# Тест: test_get_book_genre_scenarios. Проверил, что книга есть, жанр установлен: метод возвращает правильный жанр, книга есть, но жанр пустой: метод возвращает пустую строку '', книги нет: метод не падает с ошибкой, а корректно возвращает None. 
# Тест: test_favorites_operations. Проверил , что книгу можно добавить в избранное (предварительно добавив её в словарь), защиту от дублей: если добавить книгу второй раз, список не станет длиннее, книгу можно удалить из избранного, после удаления книги нет в списке.
# Тест: test_get_books_for_children_filtering. Проверил, что книга с детским жанром попадает в список, книга со взрослым жанром не попадает в список детских книг. 
# Тест: test_get_books_with_specific_genre. Проверил, что метод возвращает список книг, в списке только книги нужного жанра, книги других жанров в список не попали.
# Тест: test_get_books_genre_returns_full_dict. Проверил, что метод get_books_genre возвращает весь словарь целиком, ключи и значения в возвращенном словаре совпадают с тем, что туда положил.
